# Sundial Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a Windows desktop app in Rust that automatically tracks how long the user is present at their machine each day, shown in a small always-on-top widget with a bottom-right analytics panel.

**Architecture:** Three threads. A **tracker thread** owns all state, ticks at 1 Hz, credits elapsed monotonic time to the current local date, and flushes to disk every 30 s. A **session thread** owns a message-only Win32 window and forwards lock/unlock and power events over a channel. The **UI thread** runs eframe/winit plus the tray icon, reads an `Arc<Mutex<Snapshot>>` for display, and sends commands back. Accounting never depends on a frame being drawn, so a hidden widget still tracks correctly.

**Tech Stack:** Rust (MSVC toolchain), `eframe`/`egui`, `windows` (windows-rs), `tray-icon`, `serde`/`serde_json`, `chrono`, `winreg`.

**Spec:** `docs/superpowers/specs/2026-10-18-sundial-design.md`

## Global Constraints

- Target: Windows 10/11 x86_64 only. MSVC toolchain (`stable-x86_64-pc-windows-msvc`).
- Idle timeout default: **300 seconds**. Tick interval: **1 Hz**. Flush interval: **30 seconds**. Tick delta clamp: **5 seconds**.
- Time accrues **if and only if** `!locked && present`. `locked` takes precedence over input.
- Elapsed time comes from the **monotonic clock** (`std::time::Instant`). Wall clock (`chrono::Local`) is used *only* to decide which date a measurement belongs to.
- Totals are per **local calendar day**; a tick straddling local midnight is split at the boundary.
- Week definition: **calendar week starting Monday**.
- Daily average: mean of the **last 30 calendar days before today** that have a recorded total **> 0**; today is excluded.
- Data file: `%APPDATA%\Sundial\data.json`. Writes are atomic (temp + fsync + rename). History retained forever.
- Autostart: `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, value name `Sundial`, **off by default**.
- Theme: background `#1A1C1F` @ ~87% opacity, text `#E8EAED`, muted `#9AA0A6`, green `#4ADE80`, amber `#FBBF24`, grey `#6B7280`, corner radius 10 px.
- Widget: 140 × 40 logical px. Panel: 320 × 400 logical px.
- `tracker.rs` and `stats.rs` must contain **no** Windows API calls and **no** clock reads — all time is passed in as arguments. This is what makes them testable.
- Commit after every task. Conventional commit messages (`feat:`, `test:`, `chore:`).

```rust
use chrono::NaiveDate;
use serde::{Deserialize, Serialize};
use std::collections::BTreeMap;
use std::io::Write;
use std::path::{Path, PathBuf};
use std::time::Duration;

#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct Settings {
    pub idle_timeout_secs: u64,
    pub autostart: bool,
    pub widget_visible: bool,
}

impl Default for Settings {
    fn default() -> Self {
        Self { idle_timeout_secs: 300, autostart: false, widget_visible: true }
    }
}

#[derive(Debug, Clone, Copy, PartialEq, Serialize, Deserialize)]
pub struct WidgetPos {
    pub x: f32,
    pub y: f32,
}

#[derive(Debug, Clone, Default, PartialEq)]
pub struct Store {
    pub days: BTreeMap<NaiveDate, Duration>,
    pub settings: Settings,
    pub widget: Option<WidgetPos>,
}

#[derive(Serialize, Deserialize)]
struct Dto {
    version: u32,
    days: BTreeMap<String, u64>,
    #[serde(default)]
    settings: Settings,
    #[serde(default)]
    widget: Option<WidgetPos>,
}

const DATE_FMT: &str = "%Y-%m-%d";

impl Store {
    pub fn data_path() -> PathBuf {
        let mut p = dirs::data_dir().unwrap_or_else(std::env::temp_dir);
        p.push("Sundial");
        p.push("data.json");
        p
    }

    pub fn add(&mut self, date: NaiveDate, amount: Duration) {
        *self.days.entry(date).or_default() += amount;
    }

    pub fn load(path: &Path) -> Store {
        let text = match std::fs::read_to_string(path) {
            Ok(t) => t,
            Err(_) => return Store::default(),
        };
        match serde_json::from_str::<Dto>(&text) {
            Ok(dto) => Store {
                days: dto
                    .days
                    .into_iter()
                    .filter_map(|(k, v)| {
                        NaiveDate::parse_from_str(&k, DATE_FMT).ok().map(|d| (d, Duration::from_secs(v)))
                    })
                    .collect(),
                settings: dto.settings,
                widget: dto.widget,
            },
            Err(_) => {
                quarantine(path);
                Store::default()
            }
        }
    }

    pub fn save(&self, path: &Path) -> std::io::Result<()> {
        if let Some(parent) = path.parent() {
            std::fs::create_dir_all(parent)?;
        }
        let dto = Dto {
            version: 1,
            days: self
                .days
                .iter()
                .map(|(d, dur)| (d.format(DATE_FMT).to_string(), dur.as_secs()))
                .collect(),
            settings: self.settings.clone(),
            widget: self.widget,
        };
        let json = serde_json::to_string_pretty(&dto)?;

        let tmp = path.with_extension("json.tmp");
        {
            let mut f = std::fs::File::create(&tmp)?;
            f.write_all(json.as_bytes())?;
            f.sync_all()?;
        }
        std::fs::rename(&tmp, path)?;
        Ok(())
    }
}

fn quarantine(path: &Path) {
    let ts = std::time::SystemTime::now()
        .duration_since(std::time::UNIX_EPOCH)
        .map(|d| d.as_secs())
        .unwrap_or(0);
    let dest = path.with_extension(format!("json.corrupt-{ts}"));
    let _ = std::fs::rename(path, dest);
}
```

## Task 2: Tracker — presence state and tick accounting

**Files:**
- Create: `src/tracker.rs`
- Modify: `src/main.rs` (add `mod tracker;`)

**Interfaces:**
- Consumes: nothing
- Produces:
  - `pub enum DerivedState { Counting, IdlePaused, Locked }`
  - `pub const MAX_TICK_DELTA: Duration` (5 s)
  - `pub struct Tracker`
  - `impl Tracker { pub fn new(idle_timeout: Duration) -> Self; pub fn set_locked(&mut self, locked: bool); pub fn resume(&mut self); pub fn state(&self) -> DerivedState; pub fn tick(&mut self, mono: Duration, wall: DateTime<Local>, idle: Duration) -> Vec<(NaiveDate, Duration)> }`

`tick` is the only accounting entry point. It returns the credits the caller must apply to the store — the tracker itself owns no storage. `mono` is a monotonic reading (elapsed since process start), `wall` is local wall-clock at the same instant, `idle` is how long since the last user input.

Credits are attributed using the state as of the **previous** tick, since that is the state that held during the elapsed interval. A lock arriving mid-interval therefore over-credits by at most one tick (1 s) — conservative in the only direction that matters is not possible here, so this bound is documented and accepted rather than engineered away.

```rust
use chrono::{DateTime, Local, NaiveDate, TimeZone};
use std::time::Duration;

/// Any tick gap larger than this is discarded. This is the backstop that makes
/// sleep, suspension, or a clock jump incapable of inflating the total even when
/// the corresponding system event never arrives.
pub const MAX_TICK_DELTA: Duration = Duration::from_secs(5);

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum DerivedState {
    Counting,
    IdlePaused,
    Locked,
}

pub struct Tracker {
    idle_timeout: Duration,
    locked: bool,
    present: bool,
    /// Monotonic + wall reading of the previous tick, and whether time was
    /// accruing during the interval that ended at that tick.
    last: Option<Duration>,
    counting_since_last_tick: bool,
}

impl Tracker {
    pub fn new(idle_timeout: Duration) -> Self {
        Self {
            idle_timeout,
            locked: false,
            present: false,
            last: None,
            counting_since_last_tick: false,
        }
    }

    pub fn set_locked(&mut self, locked: bool) {
        self.locked = locked;
        if locked {
            self.counting_since_last_tick = false;
        }
        self.refresh_counting();
    }

    /// Called on resume from sleep. Drops the baseline so the sleep interval is
    /// never credited, and assumes absence until the next input is observed.
    pub fn resume(&mut self) {
        self.last = None;
        self.present = false;
        self.counting_since_last_tick = false;
    }

    pub fn state(&self) -> DerivedState {
        if self.locked {
            DerivedState::Locked
        } else if self.present {
            DerivedState::Counting
        } else {
            DerivedState::IdlePaused
        }
    }

    pub fn tick(
        &mut self,
        mono: Duration,
        wall: DateTime<Local>,
        idle: Duration,
    ) -> Vec<(NaiveDate, Duration)> {
        let credits = match self.last {
            Some(prev) if self.counting_since_last_tick => {
                let delta = mono.saturating_sub(prev);
                if delta > MAX_TICK_DELTA || delta.is_zero() {
                    Vec::new()
                } else {
                    split_at_midnight(wall, delta)
                }
            }
            _ => Vec::new(),
        };

        self.present = idle < self.idle_timeout;
        self.last = Some(mono);
        self.refresh_counting();
        credits
    }

    fn refresh_counting(&mut self) {
        self.counting_since_last_tick = !self.locked && self.present;
    }
}

/// Splits `delta` ending at `end` across local calendar dates. Because `delta`
/// is bounded by `MAX_TICK_DELTA`, it spans at most two dates.
fn split_at_midnight(end: DateTime<Local>, delta: Duration) -> Vec<(NaiveDate, Duration)> {
    let span = match chrono::Duration::from_std(delta) {
        Ok(s) => s,
        Err(_) => return Vec::new(),
    };
    let start = end - span;
    let end_date = end.date_naive();
    let start_date = start.date_naive();

    if start_date == end_date {
        return vec![(end_date, delta)];
    }

    // Local midnight at the start of `end_date`. If the timezone makes that
    // instant ambiguous or non-existent (a DST shift exactly at midnight),
    // fall back to crediting the whole delta to the earlier date rather than
    // guessing — the error is bounded by MAX_TICK_DELTA.
    let midnight = match end_date.and_hms_opt(0, 0, 0) {
        Some(naive) => match Local.from_local_datetime(&naive).earliest() {
            Some(dt) => dt,
            None => return vec![(start_date, delta)],
        },
        None => return vec![(start_date, delta)],
    };

    let after = (end - midnight).to_std().unwrap_or(Duration::ZERO);
    let after = after.min(delta);
    let before = delta - after;

    let mut out = Vec::with_capacity(2);
    if !before.is_zero() {
        out.push((start_date, before));
    }
    if !after.is_zero() {
        out.push((end_date, after));
    }
    out
}
```

```rust
use chrono::{Datelike, NaiveDate};
use std::collections::BTreeMap;
use std::time::Duration;

const AVERAGE_WINDOW_DAYS: i64 = 30;

#[derive(Debug, Clone, PartialEq)]
pub struct Summary {
    pub today: Duration,
    pub yesterday: Duration,
    pub this_week: Duration,
    pub daily_average: Duration,
    /// Monday..Sunday of the current calendar week. `None` = future day.
    pub week_series: [Option<Duration>; 7],
    /// Newest first, includes today.
    pub history: Vec<(NaiveDate, Duration)>,
}

pub fn summarize(days: &BTreeMap<NaiveDate, Duration>, today: NaiveDate) -> Summary {
    let get = |d: NaiveDate| days.get(&d).copied().unwrap_or(Duration::ZERO);

    let monday = today - chrono::Duration::days(today.weekday().num_days_from_monday() as i64);

    let mut week_series = [None; 7];
    let mut this_week = Duration::ZERO;
    for offset in 0..7i64 {
        let date = monday + chrono::Duration::days(offset);
        if date > today {
            continue; // stays None - future
        }
        let value = get(date);
        week_series[offset as usize] = Some(value);
        this_week += value;
    }

    let window_start = today - chrono::Duration::days(AVERAGE_WINDOW_DAYS);
    let tracked: Vec<Duration> = days
        .iter()
        .filter(|(d, v)| **d < today && **d >= window_start && !v.is_zero())
        .map(|(_, v)| *v)
        .collect();
    let daily_average = if tracked.is_empty() {
        Duration::ZERO
    } else {
        tracked.iter().sum::<Duration>() / tracked.len() as u32
    };

    let mut history: Vec<(NaiveDate, Duration)> = days.iter().map(|(d, v)| (*d, *v)).collect();
    history.reverse();

    Summary {
        today: get(today),
        yesterday: get(today - chrono::Duration::days(1)),
        this_week,
        daily_average,
        week_series,
        history,
    }
}

/// Monday-first weekday initials for the chart axis.
pub const WEEKDAY_INITIALS: [&str; 7] = ["M", "T", "W", "T", "F", "S", "S"];
```

```rust
use std::sync::mpsc::Sender;
use std::sync::OnceLock;
use windows::core::{w, PCWSTR};
use windows::Win32::Foundation::{HWND, LPARAM, LRESULT, WPARAM};
use windows::Win32::System::Power::{PBT_APMRESUMEAUTOMATIC, PBT_APMRESUMESUSPEND, PBT_APMSUSPEND};
use windows::Win32::System::RemoteDesktop::{
    WTSRegisterSessionNotification, WTSUnRegisterSessionNotification, NOTIFY_FOR_THIS_SESSION,
};
use windows::Win32::UI::WindowsAndMessaging::*;

static TX: OnceLock<Sender<SystemEvent>> = OnceLock::new();

const WTS_SESSION_LOCK: u32 = 0x7;
const WTS_SESSION_UNLOCK: u32 = 0x8;
const WTS_SESSION_LOGON: u32 = 0x5;
const WTS_SESSION_LOGOFF: u32 = 0x6;

fn emit(e: SystemEvent) {
    if let Some(tx) = TX.get() {
        let _ = tx.send(e);
    }
}

unsafe extern "system" fn wndproc(hwnd: HWND, msg: u32, wp: WPARAM, lp: LPARAM) -> LRESULT {
    match msg {
        WM_WTSSESSION_CHANGE => {
            match wp.0 as u32 {
                WTS_SESSION_LOCK | WTS_SESSION_LOGOFF => emit(SystemEvent::Locked),
                WTS_SESSION_UNLOCK | WTS_SESSION_LOGON => emit(SystemEvent::Unlocked),
                _ => {}
            }
            LRESULT(0)
        }
        WM_POWERBROADCAST => {
            match wp.0 as u32 {
                PBT_APMSUSPEND => emit(SystemEvent::Suspend),
                PBT_APMRESUMEAUTOMATIC | PBT_APMRESUMESUSPEND => emit(SystemEvent::Resume),
                _ => {}
            }
            LRESULT(1)
        }
        WM_DESTROY => {
            let _ = WTSUnRegisterSessionNotification(hwnd);
            PostQuitMessage(0);
            LRESULT(0)
        }
        _ => DefWindowProcW(hwnd, msg, wp, lp),
    }
}

/// Spawns a thread owning a message-only window that receives session and power
/// notifications. The thread runs a message pump for the life of the process.
pub fn spawn(tx: Sender<SystemEvent>) {
    let _ = TX.set(tx);
    std::thread::Builder::new()
        .name("sundial-session".into())
        .spawn(|| unsafe {
            let class = w!("SundialSessionWatcher");
            let hinstance = windows::Win32::System::LibraryLoader::GetModuleHandleW(PCWSTR::null())
                .expect("GetModuleHandleW");

            let wc = WNDCLASSW {
                lpfnWndProc: Some(wndproc),
                hInstance: hinstance.into(),
                lpszClassName: class,
                ..Default::default()
            };
            RegisterClassW(&wc);

            let hwnd = CreateWindowExW(
                WINDOW_EX_STYLE(0),
                class,
                w!("Sundial"),
                WINDOW_STYLE(0),
                0, 0, 0, 0,
                Some(HWND_MESSAGE),
                None,
                Some(hinstance.into()),
                None,
            )
            .expect("CreateWindowExW");

            let _ = WTSRegisterSessionNotification(hwnd, NOTIFY_FOR_THIS_SESSION);

            let mut msg = MSG::default();
            while GetMessageW(&mut msg, None, 0, 0).as_bool() {
                let _ = TranslateMessage(&msg);
                DispatchMessageW(&msg);
            }
        })
        .expect("spawn session thread");
}
```

```rust
use winreg::enums::{HKEY_CURRENT_USER, KEY_READ, KEY_WRITE};
use winreg::RegKey;

const RUN_KEY: &str = r"Software\Microsoft\Windows\CurrentVersion\Run";
const VALUE: &str = "Sundial";

fn exe_command() -> std::io::Result<String> {
    let exe = std::env::current_exe()?;
    Ok(format!("\"{}\"", exe.display()))
}

/// Reads live registry state rather than trusting settings, so a moved or
/// deleted executable self-corrects on next launch.
pub fn is_enabled() -> bool {
    let want = match exe_command() {
        Ok(c) => c,
        Err(_) => return false,
    };
    RegKey::predef(HKEY_CURRENT_USER)
        .open_subkey_with_flags(RUN_KEY, KEY_READ)
        .and_then(|k| k.get_value::<String, _>(VALUE))
        .map(|current| current.eq_ignore_ascii_case(&want))
        .unwrap_or(false)
}

pub fn set(enabled: bool) -> std::io::Result<()> {
    let key = RegKey::predef(HKEY_CURRENT_USER).open_subkey_with_flags(RUN_KEY, KEY_WRITE)?;
    if enabled {
        key.set_value(VALUE, &exe_command()?)
    } else {
        match key.delete_value(VALUE) {
            Err(e) if e.kind() == std::io::ErrorKind::NotFound => Ok(()),
            other => other,
        }
    }
}
```

```rust
use crate::platform::{self, SystemEvent};
use crate::stats::{self, Summary};
use crate::store::{Settings, Store};
use crate::tracker::{DerivedState, Tracker};
use chrono::Local;
use std::path::PathBuf;
use std::sync::mpsc::{channel, Receiver, Sender};
use std::sync::{Arc, Mutex};
use std::time::{Duration, Instant};

const TICK: Duration = Duration::from_secs(1);
const FLUSH_EVERY: Duration = Duration::from_secs(30);

#[derive(Debug, Clone)]
pub struct Snapshot {
    pub today: Duration,
    pub state: DerivedState,
    pub summary: Summary,
}

#[derive(Debug, Clone, Copy)]
pub enum Command {
    SetWidgetPos(f32, f32),
    SetAutostart(bool),
    SetWidgetVisible(bool),
    Flush,
    Quit,
}

pub struct Engine {
    pub snapshot: Arc<Mutex<Snapshot>>,
    pub settings: Arc<Mutex<Settings>>,
    pub commands: Sender<Command>,
    pub initial_widget_pos: Option<crate::store::WidgetPos>,
}

pub fn start() -> Engine {
    let path = Store::data_path();
    let store = Store::load(&path);

    let settings = Arc::new(Mutex::new(store.settings.clone()));
    let initial_widget_pos = store.widget;
    let today = Local::now().date_naive();

    let snapshot = Arc::new(Mutex::new(Snapshot {
        today: store.days.get(&today).copied().unwrap_or_default(),
        state: DerivedState::IdlePaused,
        summary: stats::summarize(&store.days, today),
    }));

    let (events_tx, events_rx) = channel::<SystemEvent>();
    platform::session::spawn(events_tx);

    let (cmd_tx, cmd_rx) = channel::<Command>();

    {
        let snapshot = Arc::clone(&snapshot);
        let settings = Arc::clone(&settings);
        std::thread::Builder::new()
            .name("sundial-engine".into())
            .spawn(move || run(store, path, snapshot, settings, events_rx, cmd_rx))
            .expect("spawn engine thread");
    }

    Engine { snapshot, settings, commands: cmd_tx, initial_widget_pos }
}

fn run(
    mut store: Store,
    path: PathBuf,
    snapshot: Arc<Mutex<Snapshot>>,
    settings: Arc<Mutex<Settings>>,
    events: Receiver<SystemEvent>,
    commands: Receiver<Command>,
) {
    let idle_timeout = Duration::from_secs(store.settings.idle_timeout_secs);
    let mut tracker = Tracker::new(idle_timeout);
    let origin = Instant::now();
    let mut last_flush = Instant::now();
    let mut dirty = false;

    loop {
        std::thread::sleep(TICK);

        while let Ok(event) = events.try_recv() {
            match event {
                SystemEvent::Locked => tracker.set_locked(true),
                SystemEvent::Unlocked => tracker.set_locked(false),
                SystemEvent::Suspend => {
                    let _ = store.save(&path);
                    last_flush = Instant::now();
                    dirty = false;
                }
                SystemEvent::Resume => tracker.resume(),
            }
        }

        let mut quit = false;
        while let Ok(cmd) = commands.try_recv() {
            match cmd {
                Command::SetWidgetPos(x, y) => {
                    store.widget = Some(crate::store::WidgetPos { x, y });
                    dirty = true;
                }
                Command::SetAutostart(on) => {
                    let _ = platform::autostart::set(on);
                    store.settings.autostart = on;
                    settings.lock().unwrap().autostart = on;
                    dirty = true;
                }
                Command::SetWidgetVisible(v) => {
                    store.settings.widget_visible = v;
                    settings.lock().unwrap().widget_visible = v;
                    dirty = true;
                }
                Command::Flush => dirty = true,
                Command::Quit => quit = true,
            }
        }

        let credits = tracker.tick(
            origin.elapsed(),
            Local::now(),
            platform::idle::since_last_input(),
        );
        for (date, amount) in &credits {
            store.add(*date, *amount);
            dirty = true;
        }

        let today = Local::now().date_naive();
        {
            let mut snap = snapshot.lock().unwrap();
            snap.today = store.days.get(&today).copied().unwrap_or_default();
            snap.state = tracker.state();
            snap.summary = stats::summarize(&store.days, today);
        }

        if quit {
            let _ = store.save(&path);
            return;
        }
        if dirty && last_flush.elapsed() >= FLUSH_EVERY {
            let _ = store.save(&path);
            last_flush = Instant::now();
            dirty = false;
        }
    }
}
```

```rust
use egui::Color32;
use std::time::Duration;

pub const BG: Color32 = Color32::from_rgba_premultiplied(26, 28, 31, 222);
pub const TEXT: Color32 = Color32::from_rgb(232, 234, 237);
pub const MUTED: Color32 = Color32::from_rgb(154, 160, 166);
pub const GREEN: Color32 = Color32::from_rgb(74, 222, 128);
pub const AMBER: Color32 = Color32::from_rgb(251, 191, 36);
pub const GREY: Color32 = Color32::from_rgb(107, 114, 128);
pub const RADIUS: f32 = 10.0;

pub fn apply(ctx: &egui::Context) {
    let mut style = (*ctx.style()).clone();
    style.visuals.panel_fill = Color32::TRANSPARENT;
    style.visuals.window_fill = BG;
    style.visuals.override_text_color = Some(TEXT);
    style.visuals.window_stroke = egui::Stroke::NONE;
    ctx.set_style(style);
}

/// `HH:MM:SS` for the widget.
pub fn fmt_clock(d: Duration) -> String {
    let s = d.as_secs();
    format!("{:02}:{:02}:{:02}", s / 3600, (s % 3600) / 60, s % 60)
}

/// `4h 12m` for the panel. Under an hour, `12m`.
pub fn fmt_human(d: Duration) -> String {
    let s = d.as_secs();
    let (h, m) = (s / 3600, (s % 3600) / 60);
    if h > 0 { format!("{h}h {m:02}m") } else { format!("{m}m") }
}
```

```rust
pub fn show(ui: &mut egui::Ui, snap: &Snapshot) -> WidgetAction {
    let rect = ui.max_rect();

        FontId::monospace(16.0),
        theme::TEXT,

        action = WidgetAction::StartDrag;
    } else if response.clicked() {
        action = WidgetAction::TogglePanel;
```

```rust
use crate::engine::{Command, Engine};
use crate::ui::{theme, widget};
use egui::ViewportCommand;
use std::time::Duration;

pub struct SundialApp {
    engine: Engine,
    pub panel_open: bool,
    last_pos: Option<egui::Pos2>,
}

impl SundialApp {
    pub fn new(cc: &eframe::CreationContext<'_>, engine: Engine) -> Self {
        theme::apply(&cc.egui_ctx);
        Self { engine, panel_open: false, last_pos: None }
    }
}

impl eframe::App for SundialApp {
    fn clear_color(&self, _visuals: &egui::Visuals) -> [f32; 4] {
        [0.0, 0.0, 0.0, 0.0]
    }

    fn update(&mut self, ctx: &egui::Context, _frame: &mut eframe::Frame) {
        ctx.request_repaint_after(Duration::from_millis(500));

        let snap = self.engine.snapshot.lock().unwrap().clone();

        egui::CentralPanel::default()
            .frame(egui::Frame::none())
            .show(ctx, |ui| {
                match widget::show(ui, &snap) {
                    widget::WidgetAction::StartDrag => ctx.send_viewport_cmd(ViewportCommand::StartDrag),
                    widget::WidgetAction::TogglePanel => self.panel_open = !self.panel_open,
                    widget::WidgetAction::Hide => {
                        let _ = self.engine.commands.send(Command::SetWidgetVisible(false));
                        ctx.send_viewport_cmd(ViewportCommand::Visible(false));
                    }
                    widget::WidgetAction::ToggleAutostart => {
                        let now = self.engine.settings.lock().unwrap().autostart;
                        let _ = self.engine.commands.send(Command::SetAutostart(!now));
                    }
                    widget::WidgetAction::Quit => {
                        let _ = self.engine.commands.send(Command::Quit);
                        ctx.send_viewport_cmd(ViewportCommand::Close);
                    }
                    widget::WidgetAction::None => {}
                }
            });

        // Persist the widget position whenever the OS drag finishes.
        if let Some(rect) = ctx.input(|i| i.viewport().outer_rect) {
            let pos = rect.min;
            if self.last_pos.map_or(true, |p| p != pos) {
                self.last_pos = Some(pos);
                let _ = self.engine.commands.send(Command::SetWidgetPos(pos.x, pos.y));
            }
        }
    }
}
```

```rust
use egui::{Pos2, Rect, Vec2};
use windows::Win32::Foundation::POINT;
use windows::Win32::Graphics::Gdi::{
    GetMonitorInfoW, MonitorFromPoint, MONITORINFO, MONITOR_DEFAULTTONEAREST,
};

const MARGIN: f32 = 12.0;

/// Bottom-right corner of the *work area* (i.e. excluding the taskbar) of the
/// monitor containing `widget`, inset by a margin. Using the work area rather
/// than screen dimensions is what makes this correct with the taskbar on any
/// edge, on a secondary monitor, and at non-100% DPI scaling.
pub fn bottom_right_for(widget: Rect, size: Vec2) -> Pos2 {
    let centre = widget.center();
    let point = POINT { x: centre.x as i32, y: centre.y as i32 };

    unsafe {
        let hmon = MonitorFromPoint(point, MONITOR_DEFAULTTONEAREST);
        let mut info = MONITORINFO {
            cbSize: std::mem::size_of::<MONITORINFO>() as u32,
            ..Default::default()
        };
        if GetMonitorInfoW(hmon, &mut info).as_bool() {
            let work = info.rcWork;
            return Pos2::new(
                work.right as f32 - size.x - MARGIN,
                work.bottom as f32 - size.y - MARGIN,
            );
        }
    }
    // Fallback: place it relative to the widget.
    Pos2::new(widget.right() - size.x, widget.top() - size.y - MARGIN)
}
```

> `bottom_right_for` works in physical pixels, which is what `ViewportBuilder::with_position` expects. Do not scale by `ctx.pixels_per_point()`.

```rust
use super::theme;
use crate::stats::WEEKDAY_INITIALS;
use egui::{Align2, FontId, Rect, Vec2};
use std::time::Duration;

const BAR_AREA_HEIGHT: f32 = 64.0;
const LABEL_HEIGHT: f32 = 16.0;

/// Monday-first 7-bar chart. `None` entries (future days) render as nothing.
/// `today_index` is highlighted; hovering a bar reveals its exact duration.
pub fn show(ui: &mut egui::Ui, series: &[Option<Duration>; 7], today_index: usize) {
    let total_height = BAR_AREA_HEIGHT + LABEL_HEIGHT + 4.0;
    let (rect, _) = ui.allocate_exact_size(
        Vec2::new(ui.available_width(), total_height),
        egui::Sense::hover(),
    );

    let peak = series
        .iter()
        .filter_map(|v| *v)
        .map(|d| d.as_secs_f32())
        .fold(1.0_f32, f32::max);

    let slot = rect.width() / 7.0;
    let bar_width = (slot * 0.44).min(18.0);

    for (i, value) in series.iter().enumerate() {
        let centre_x = rect.left() + slot * (i as f32 + 0.5);
        let baseline = rect.top() + BAR_AREA_HEIGHT;

        if let Some(v) = value {
            let frac = (v.as_secs_f32() / peak).clamp(0.0, 1.0);
            let height = (frac * BAR_AREA_HEIGHT).max(2.0);
            let bar = Rect::from_min_max(
                egui::pos2(centre_x - bar_width / 2.0, baseline - height),
                egui::pos2(centre_x + bar_width / 2.0, baseline),
            );
            let colour = if i == today_index { theme::GREEN } else { theme::GREY };
            ui.painter().rect_filled(bar, 3.0, colour);

            let response = ui.interact(bar, ui.id().with(("bar", i)), egui::Sense::hover());
            if response.hovered() {
                response.on_hover_text(theme::fmt_human(*v));
            }
        }

        let label_colour = if i == today_index { theme::TEXT } else { theme::MUTED };
        ui.painter().text(
            egui::pos2(centre_x, baseline + LABEL_HEIGHT),
            Align2::CENTER_BOTTOM,
            WEEKDAY_INITIALS[i],
            FontId::proportional(10.0),
            label_colour,
        );
    }
}
```

```rust
use tray_icon::menu::{CheckMenuItem, Menu, MenuEvent, MenuItem, PredefinedMenuItem};
use tray_icon::{TrayIcon, TrayIconBuilder, TrayIconEvent};

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum TrayAction {
    None,
    ToggleWidget,
    ShowAnalytics,
    ToggleAutostart,
    Quit,
}

pub struct Tray {
    _icon: TrayIcon,
    toggle_id: tray_icon::menu::MenuId,
    analytics_id: tray_icon::menu::MenuId,
    autostart_id: tray_icon::menu::MenuId,
    quit_id: tray_icon::menu::MenuId,
    pub autostart_item: CheckMenuItem,
}

fn load_icon() -> tray_icon::Icon {
    let bytes = include_bytes!("../assets/icon.png");
    let image = image::load_from_memory(bytes).expect("icon.png").into_rgba8();
    let (w, h) = image.dimensions();
    tray_icon::Icon::from_rgba(image.into_raw(), w, h).expect("icon rgba")
}

impl Tray {
    pub fn new(autostart: bool) -> Option<Tray> {
        let toggle = MenuItem::new("Show/Hide widget", true, None);
        let analytics = MenuItem::new("Analytics", true, None);
        let autostart_item = CheckMenuItem::new("Start with Windows", true, autostart, None);
        let quit = MenuItem::new("Quit", true, None);

        let menu = Menu::new();
        menu.append(&toggle).ok()?;
        menu.append(&analytics).ok()?;
        menu.append(&PredefinedMenuItem::separator()).ok()?;
        menu.append(&autostart_item).ok()?;
        menu.append(&PredefinedMenuItem::separator()).ok()?;
        menu.append(&quit).ok()?;

        let icon = TrayIconBuilder::new()
            .with_menu(Box::new(menu))
            .with_tooltip("Sundial")
            .with_icon(load_icon())
            .build()
            .ok()?;

        Some(Tray {
            _icon: icon,
            toggle_id: toggle.id().clone(),
            analytics_id: analytics.id().clone(),
            autostart_id: autostart_item.id().clone(),
            quit_id: quit.id().clone(),
            autostart_item,
        })
    }

    /// Drains tray and menu events. Call once per frame.
    pub fn poll(&self) -> TrayAction {
        let mut action = TrayAction::None;

        while let Ok(event) = TrayIconEvent::receiver().try_recv() {
            if let TrayIconEvent::Click { button: tray_icon::MouseButton::Left, .. } = event {
                action = TrayAction::ToggleWidget;
            }
        }

        while let Ok(MenuEvent { id }) = MenuEvent::receiver().try_recv() {
            action = if id == self.toggle_id {
                TrayAction::ToggleWidget
            } else if id == self.analytics_id {
                TrayAction::ShowAnalytics
            } else if id == self.autostart_id {
                TrayAction::ToggleAutostart
            } else if id == self.quit_id {
                TrayAction::Quit
            } else {
                action
            };
        }

        action
    }
}
```

```rust
                    let _ = self.engine.commands.send(Command::SetWidgetVisible(self.widget_visible));
                }
                crate::tray::TrayAction::ShowAnalytics => self.panel_open = true,
                crate::tray::TrayAction::ToggleAutostart => {
                    let now = self.engine.settings.lock().unwrap().autostart;
                    let _ = self.engine.commands.send(Command::SetAutostart(!now));
                    tray.autostart_item.set_checked(!now);
                }
                crate::tray::TrayAction::Quit => {
                    let _ = self.engine.commands.send(Command::Quit);
                    ctx.send_viewport_cmd(ViewportCommand::Close);
                }
                crate::tray::TrayAction::None => {}
            }
        }
```

Also update the widget's `Hide` arm to set `self.widget_visible = false`, and the `ToggleAutostart` arm to call `tray.autostart_item.set_checked(..)` so both entry points stay in sync.

```markdown
# Sundial

A small Windows app that tracks how long you are actually at your machine each day.

Time counts while your session is unlocked and you have used the keyboard or mouse
within the last 5 minutes. Locking, sleeping, or walking away pauses it. Totals reset
at local midnight; a session crossing midnight is split across both days.

## Usage

- The floating widget shows today's total. Drag to move, click to open analytics.
- The dot is green while counting, amber while idle, grey while locked.
- Right-click the widget or use the tray icon to hide it, open analytics, toggle
  "Start with Windows", or quit. Hiding does not stop tracking.
- Press Esc or click elsewhere to dismiss the analytics panel.

## Data

`%APPDATA%\Sundial\data.json` — one entry per day, in seconds. Edit `idle_timeout_secs`
there to change the 5-minute idle threshold.

    cargo build --release

Output: `target/release/sundial.exe` — self-contained, no installer.
```
