Know how long you're actually at your PC.

Sundial is a tiny Windows app that counts your real time at the keyboard each day, and pauses the moment you lock, sleep, or walk away.

Features

Small, quiet, and honest.

Floating widget

Today's total, always in view, in three sizes. Light or dark, or match Windows. Drag it anywhere; it remembers where you left it.

At-a-glance analytics

Yesterday, this week, a 30-day daily average, a 7-day chart, and your full history.

Lightweight

How it counts

Time counts only when you're there.

Your session must be unlocked and you must have used the keyboard or mouse in the last 5 minutes. The dot tells you which state you're in.

CountingYou're active and the clock is running.
IdleNo input for 5 minutes, so the clock pauses until you're back.
LockedLocked, asleep, or signed out. Nothing counts.

The 5-minute grace window is deliberate: it keeps the timer running while you read. So the total can exceed your true presence by at most one idle timeout per absence. Sleep, crashes, and clock changes can never inflate it, and totals split cleanly at midnight.

Install

Up and running in a minute.

Install

  1. Download sundial-setup.exe from the latest release.
  2. Run it. No admin rights needed: it installs for your user only and can start with Windows.
  3. If SmartScreen says "Windows protected your PC", choose More info → Run anyway. That's because Sundial isn't code-signed yet (see below).

Prefer no installer? Each release also includes a portable .exe.

Update or remove

  • Update: run the newer setup. It closes Sundial, upgrades in place, and keeps your history.
  • Uninstall: Settings → Apps → Sundial. It closes the app, removes autostart, and asks whether to delete your history.
  • Your data: %APPDATA%\Sundial\data.json. Edit idle_timeout_secs there to change the 5-minute threshold.
Privacy

Nothing leaves your PC.

Sundial makes no network connections of any kind. It records only how many seconds you were present each day, in a file on your own machine. It doesn't capture keystrokes, screens, window titles, or app usage, and it has no analytics or telemetry.

Code signing policy

Built in the open.

  • Every release is built automatically by GitHub Actions from a tagged commit in this repository, with no manual build steps.
  • Sundial is applying to SignPath Foundation for free code signing for open-source projects. Until then, releases are unsigned; each release publishes SHA-256 checksums.
